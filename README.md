# PULSO Energy

Landing page 3D de um energético fictício, feita como projeto de portfólio.

**Ver online:** https://cors16.github.io/pulso-energetico/

- Lata 3D gerada em código com Three.js (r128), com efeito de lata recém-saída do freezer: vapor, gotas escorrendo, gelo e cristais.
- A lata gira e troca de sabor conforme o scroll; o fundo muda de cor a cada sabor.
- Seção "Dentro da lata": a lata desmonta em etapas, com etiquetas nas peças, líquido com gás e tabela nutricional.

Sabores e esportes: Original (skate), Açaí (snowboard), Maracujá (downhill) e Melancia Zero (surf).

PULSO é uma marca fictícia. Os valores nutricionais são ilustrativos.
